# Data Cleaning — Titanic Dataset

## Objective
Clean the Titanic dataset by handling missing values, 
removing duplicates, standardising formatting, 
fixing data types, and detecting outliers.

## Dataset
Titanic Dataset from Kaggle (891 rows, 12 columns)

## Steps Performed
1. Data quality report
2. Missing value handling
3. Duplicate removal
4. Text standardisation
5. Data type correction
6. Outlier detection and capping
7. Saved cleaned dataset

## Tools Used
Python, Pandas, NumPy, Jupyter Notebook
